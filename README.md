# 3D FPS 射击游戏 Demo

一个 Unity 做的第一人称射击小游戏。地图、人物和枪械模型用的是现成素材，自己写代码实现了角色控制、枪械系统、射击和对象池这些逻辑。

## 里面做了啥

角色和枪械：

- 第一人称视角，能走路和奔跑
- 奔跑的时候持枪姿势会变，停下来又恢复，两个状态手动调了枪械和手的位置，保证跑和站的时候手都贴在枪上
- 开枪有后坐力，用 Lerp 做的插值，枪口会往上抬、带点左右偏移，打完自动回正

射击系统：

- 子弹从枪口位置生成，枪口是在枪上挂的一个空物体定位的
- 子弹用了**对象池**，不反复 Instantiate/Destroy，避免 GC 卡顿
- 打到东西有反馈特效，弹孔和火花会贴着被打的那个面（按碰撞法线转方向）
- 场景里放了一个怪物，打中会触发爆炸特效然后消失

UI：

- 用 UGUI 搭了主菜单和游戏内 HUD（血量、弹药、准星）

## 操作

| 按键 | 作用 |
|---|---|
| W A S D | 移动 |
| Shift | 奔跑 |
| 鼠标左键 | 射击 |
| 鼠标移动 | 转向 |

## 代码结构

脚本主要分几块：

- 玩家控制：走路、奔跑状态切换，和枪械姿势联动
- 枪械：射击逻辑、后坐力、枪口定位
- 子弹：对象池管理、飞行、命中检测、命中特效
- 怪物：受击、爆炸反馈
- UI：主菜单、HUD

## 说一下对象池

这个项目里子弹和命中特效都走对象池。思路就是：子弹不用的时候不销毁，而是 SetActive(false) 放回池子里，下次开枪先从池子里找空闲的，没有再 Instantiate 新的。这样频繁开枪的时候不会一直创建销毁对象，减少 GC 造成的卡顿。

## 怎么运行

用 Unity 打开项目，进主场景点播放就行。
